# Escape map artwork

`Kirk Sprite Sheet.png`, `Diddy Sprite Sheet.png`, `Epstein Sprite Sheet.png`, and `Pixel-Art Base Avatar Selection Sheet.png` were supplied by the project owner for boss encounters and selectable player avatars. Their original generation prompts and provenance were not supplied. The previously supplied `Tumz Sprite Sheet.png` remains in the repository but is not used by the current boss encounters.

`mascot.png` was supplied by the project owner as a six-pose mascot sheet. The app selects poses using CSS; the original image is unmodified. Its generation prompt and provenance were not supplied.

`island-board-v2.png` was edited from `escape-island.png` with the built-in image generation tool, using the user's game-board reference for visual direction. Prompt: "Edit the existing tropical island illustration into a polished mobile game board backdrop inspired by a scenic lush 3D game world and turquoise water. Preserve the island, vegetation, lighthouse, harbor and warm adventurous identity, but remove its baked-in winding trail so that a separate interactive route can be overlaid in code. Create a portrait backdrop filling the phone screen, with turquoise sea, jungle islands, sunlit cliffs and a few soft clouds. Keep the center calm for 30 overlaid buttons; no UI, text, numbers, checkpoints, characters, treasure chests, borders, or watermarks."

`escape-island.png` is an original island map generated with the built-in image generation tool and shipped as a game background.

Prompt: “Create a polished 2D mobile game background illustration, portrait 2:3 composition, for a friendly but ominous tropical island escape game. Top-down oblique game map with a long winding creamy sand footpath beginning at bottom center beach, snaking up through dense dark teal and sage palm trees, crossing a small wooden bridge over turquoise water in the middle, past a tiny old peach mansion near upper-left, and ending at a small lighthouse and escape sailboat near top-right. Bold simple hand-painted vector-like shapes with gently rounded silhouettes, flat clean color fields, subtle paper-like painted detail, appealing original indie game art, muted lush greens, warm ivory sand, apricot coral accents, pale blue-green water. No people, absolutely no letters, words, numbers, map markers, circles, icons, UI, borders, or typography. Keep clear open sand areas along the wide winding path so numbered interactive checkpoints can be overlaid in code. Cohesive sophisticated bright daytime palette, generous breathing room, professional game asset, not photorealistic.”
